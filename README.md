# Агент

Плагин Obsidian. На iPad тоже: он не запускает локальные процессы, а ходит в OpenAI-совместимый API и пишет в хранилище сам.

Умеет прочитать заметку, посмотреть png, jpeg, gif или webp, заменить фрагмент, переписать файл или создать папку, найти что-то в сети и прочитать страницу по адресу. HEIC не отправляет.

## Поиск в сети

Тумблер «Поиск в сети» в настройках даёт агенту два инструмента без ключа: `web_search` ищет через DuckDuckGo и возвращает заголовки, адреса и сниппеты, `fetch_url` скачивает страницу по адресу и отдаёт модели её текст без разметки. Тумблер включён по умолчанию и после обновления у старых установок тоже: если сеть агенту не нужна — выключи его. Выключенный тумблер скрывает оба инструмента, модель про них не знает. Текст из сети агент считает данными, а не инструкциями: писать его в заметку он будет только по заданию пользователя.

## Сборка

```sh
npm install
npm test
npm run build
```

В папке должны лежать `manifest.json`, `main.js` и `styles.css`.

## iPad

Всё делается в Obsidian на планшете. Компьютер для установки не нужен.

1. Настройки → сторонние плагины → выключить ограниченный режим.
2. Обзор → найти BRAT → установить и включить.
3. Палитра команд → «BRAT: Add a beta plugin for testing».
4. Вставить `omfg74/obsidian-agent`.
5. Включить «Агент». Команда: «Агент: Открыть».

Ключ лежит в `.obsidian/plugins/obsidian-agent/data.json` внутри хранилища.

## Настройки

Провайдеров может быть несколько. В настройках провайдер добавляется из преднастройки: OpenCode, OpenRouter, OpenAI, Gemini, Groq, DeepSeek, Mistral, xAI, Anthropic, Cerebras, Fireworks, SambaNova, Hugging Face, NVIDIA, MiniMax, Cohere, Perplexity, Moonshot, свой адрес или локальная модель. У преднастройки подставляется адрес API. Свой адрес и локальная модель адрес не заполняют. Локальная модель — это OpenAI-совместимый сервер по адресу в сети, например `http://192.168.1.10:11434/v1`. На iPad процесс модели не запускается. Ключ у локальной модели не обязателен.

Адрес без хвоста `/chat/completions`. Список моделей берётся с `GET /models` выбранного провайдера. У OpenCode список лежит на `https://opencode.ai/inference/v1/models`, а чат — на `https://opencode.ai/inference/openai/v1/chat/completions`. У Perplexity чат на `https://api.perplexity.ai/chat/completions`, список — на `https://api.perplexity.ai/v1/models`. В список OpenCode попадают только модели chat completions: Claude, GPT и Gemini там отвечают другим API. Бесплатные модели OpenCode снаружи отвечают 403. Если в ответе есть цена и входные типы, у модели написано `платно` или `бесплатно` и `картинки` или `без картинок`. У Hugging Face цена лежит в другом поле, подписи «платно» или «бесплатно» не будет. В чате подпись стоит справа от имени и не обрезается. Нет подписи — провайдер этого не прислал, плагин сам не угадывает. В чате сверху переключаются провайдер и модель. У поля ввода переключается режим. chat читает заметки, папки и картинки и ничего не меняет. write читает файлы и картинки и правит текст, папки не создаёт. all делает то же, что write, и ещё смотрит список папок, создаёт их и убирает файлы в корзину через `delete_note`. Режим delete читает хранилище и только убирает файлы в корзину: писать и править он не может. Удаление в обоих режимах отправляет файл в корзину Obsidian, а не стирает безвозвратно. Режим запоминается. Старые настройки открываются в all.

«Новый чат» начинает пустой контекст. Прежний чат остаётся в списке и открывается снова. Картинки в сохранённый контекст не пишутся: после перезапуска Obsidian модель их не видит, в чате это написано. Ответ агента рисуется как Markdown: жирный текст, код, списки и блоки. Текст ответа можно выделить. Копирование берёт исходный текст.

У поля ввода счётчик показывает контекст всего чата, как его насчитал провайдер. Вход последнего ответа уже содержит историю: к нему прибавляется сам ответ. Если провайдер прислал только токены нового сообщения, они прибавляются к уже накопленному. Кусок потока с одним ответом не затирает вход всего чата. Если в списке моделей есть размер окна, рядом написано и оно, и доля заполнения. Нет числа — провайдер его не прислал, плагин сам не считает.

Открой заметку, напиши задание. Заметки и ответы агент пишет так, чтобы их было можно прочитать с первого раза: сначала суть, потом детали. В чате он говорит коротко, содержание оставляет в заметке. Чужой текст правит в том же голосе. В режиме редактирования правка отменяется обычной отменой и сразу пишется в файл. В режиме чтения она пишется в файл, отмена редактора её не вернёт. Закрытый файл отмена редактора не вернёт.
