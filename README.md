# Агент

Плагин Obsidian. На iPad тоже: он не запускает локальные процессы, а ходит в OpenAI-совместимый API и пишет в хранилище сам.

Умеет прочитать заметку, посмотреть png, jpeg, gif или webp, заменить фрагмент или переписать файл. HEIC не отправляет.

## Сборка

```sh
npm install
npm test
npm run build
```

В папке должны лежать `manifest.json`, `main.js` и `styles.css`.

## iPad

Всё делается в Obsidian на планшете. Компьютер для установки не нужен.

1. Настройки → сторонние плагины → выключить ограниченный режим.
2. Обзор → найти BRAT → установить и включить.
3. Палитра команд → «BRAT: Add a beta plugin for testing».
4. Вставить `omfg74/obsidian-agent`.
5. Включить «Агент». Команда: «Агент: Открыть».

Ключ лежит в `.obsidian/plugins/obsidian-agent/data.json` внутри хранилища.

## Настройки

Провайдеров может быть несколько. В настройках провайдер добавляется из преднастройки: OpenCode, OpenRouter, OpenAI, Gemini, Groq, DeepSeek, Mistral, xAI, Anthropic, Cerebras, Fireworks, SambaNova, Hugging Face, NVIDIA, MiniMax, Cohere, Perplexity, Moonshot, свой адрес или локальная модель. У преднастройки подставляется адрес API. Свой адрес и локальная модель адрес не заполняют. Локальная модель — это OpenAI-совместимый сервер по адресу в сети, например `http://192.168.1.10:11434/v1`. На iPad процесс модели не запускается. Ключ у локальной модели не обязателен.

Адрес без хвоста `/chat/completions`. Список моделей берётся с `GET /models` выбранного провайдера. У OpenCode список лежит на `https://opencode.ai/inference/v1/models`, а чат — на `https://opencode.ai/inference/openai/v1/chat/completions`. У Perplexity чат на `https://api.perplexity.ai/chat/completions`, список — на `https://api.perplexity.ai/v1/models`. В список OpenCode попадают только модели chat completions: Claude, GPT и Gemini там отвечают другим API. Бесплатные модели OpenCode снаружи отвечают 403. Если в ответе есть цена и входные типы, у модели написано `платно` или `бесплатно` и `картинки` или `без картинок`. У Hugging Face цена лежит в другом поле, подписи «платно» или «бесплатно» не будет. В чате подпись стоит справа от имени и не обрезается. Нет подписи — провайдер этого не прислал, плагин сам не угадывает. В чате сверху переключаются провайдер и модель.

«Новый чат» начинает пустой контекст. Прежний чат остаётся в списке и открывается снова. Картинки в сохранённый контекст не пишутся: после перезапуска Obsidian модель их не видит, в чате это написано.

У поля ввода счётчик показывает токены последнего ответа: вход и сам ответ, как их насчитал провайдер. Если в списке моделей есть размер окна, рядом написано и оно, и доля заполнения. Нет числа — провайдер его не прислал, плагин сам не считает.

Открой заметку, напиши задание. Правка открытой заметки отменяется обычной отменой в редакторе. Чужой файл отмена редактора не вернёт.
