# Агент

Плагин Obsidian. На iPad тоже: он не запускает локальные процессы, а ходит в OpenAI-совместимый API и пишет в хранилище сам.

Умеет прочитать заметку, посмотреть png, jpeg, gif или webp, заменить фрагмент или переписать файл. HEIC не отправляет.

## Сборка

```sh
npm install
npm test
npm run build
```

В папке должны лежать `manifest.json`, `main.js` и `styles.css`.

## iPad

Всё делается в Obsidian на планшете. Компьютер для установки не нужен.

1. Настройки → сторонние плагины → выключить ограниченный режим.
2. Обзор → найти BRAT → установить и включить.
3. Палитра команд → «BRAT: Add a beta plugin for testing».
4. Вставить `omfg74/obsidian-agent`.
5. Включить «Агент». Команда: «Агент: Открыть».

Ключ лежит в `.obsidian/plugins/obsidian-agent/data.json` внутри хранилища.

## Настройки

Провайдеров может быть несколько. У каждого свой адрес, ключ и модель. Адрес без хвоста `/chat/completions`. Список моделей берётся с `GET /models` выбранного провайдера. В чате сверху переключается активный.

Открой заметку, напиши задание. Правка открытой заметки отменяется обычной отменой в редакторе. Чужой файл отмена редактора не вернёт.
